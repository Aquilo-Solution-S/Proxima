## Single License for All Components

The entire project — core engine, flavors, shell, and documentation —
uses Apache-2.0. This includes:

- `crates/core/` (`proxima-core`)
- `flavors/<name>/`
- `apps/proxima-shell/`
- `docs/`

## What This Means

**Apache-2.0** allows anyone to:

- Use Proxima for any purpose (commercial, non-commercial, internal, public)
- Modify the source code
- Redistribute original or modified versions
- Use in proprietary products without obligation to open-source derivatives

Standard patent grant applies. This is the standard choice for ecosystem
foundation projects intended for wide adoption.

## Contributing

External contributions require a Contributor License Agreement (CLA)
granting Aquilo the right to relicense contributions as part of
commercial offerings. Mechanism:

1. CLA Assistant GitHub Action on the upstream repository
2. CLA text: standard "you keep your copyright; you grant Aquilo a
   non-exclusive, irrevocable license to relicense" form
3. DCO sign-off (`Signed-off-by:` trailer) is welcome but does not
   substitute for the CLA

## Why Apache 2.0

Apache 2.0 maximizes adoption and ecosystem growth. Companies can use
Proxima in proprietary products without legal friction, which drives
wider deployment, more contributors, and a healthier community.

The open source project serves as the marketing engine for Aquilo's
commercial offerings (hosting, enterprise features, services).
